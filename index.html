코드 (주석과 키워드는 이탤릭)

// 사용자 목록에서 활성 계정만 골라냅니다
type User = { id: number; name: string; active: boolean };

const findActive = (users: User[]): User[] =>
  users.filter((u) => u.active === true && u.id !== 0);

function compare(a: number, b: number): number {
  if (a == b) return 0;          // 같으면 0
  return a <= b ? -1 : 1;
}

for (const user of findActive(users)) {
  if (user.name != "" && user.id >= 1)
    console.log(`${user.name}님, 안녕하세요! (#${user.id})`);
}

KNPS Kkomi Mono는 국립공원 꼬미체를 고정폭으로 바꾼 폰트입니다.
본 저작물은 국립공원공단에서 2021년 작성하여 공공누리 제1유형으로 개방한 국립공원공단 꼬미(작성자: 국립공원공단)를 이용하였으며, 해당 저작물은 국립공원공단, http://www.knps.or.kr 에서 무료로 다운받으실 수 있습니다.
