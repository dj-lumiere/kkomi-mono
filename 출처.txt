KNPS Kkomi Mono

이 폰트는 국립공원공단의 "국립공원 꼬미" 서체(KNPS Kkomi, Version 1.000)를
고정폭으로 바꾼 것입니다.

본 저작물은 국립공원공단에서 2021년 작성하여 공공누리 제1유형으로 개방한 국립공원공단 꼬미(작성자: 국립공원공단)를 이용하였으며, 해당 저작물은 국립공원공단, http://www.knps.or.kr 에서 무료로 다운받으실 수 있습니다.

공공누리 안내: https://www.kogl.or.kr/recommend/recommendDivView.do?recommendIdx=41248&division=font

바꾼 내용:
- 라틴 문자와 기호를 한 칸(500), 한글을 두 칸(1000)으로 맞췄습니다.
- 모든 글자를 세로로 1.15배 늘리고, 두꺼워진 가로획은 원래 굵기로 되돌렸습니다(줄 높이 1.32em).
- 넓은 라틴 문자는 가로로 줄이고 세로획 굵기를 일부 보정했습니다.
- 한글은 두 칸을 채우도록 키우고(가로는 글자마다 최대 1.6배, 세로 1.04배), 획 굵기는 다시 깎아 맞췄습니다.
- 0 가운데에 점을 넣고, i를 막대와 둥근 모서리 마름모 점으로 바꾸고(j의 점도 같은 마름모), l은 둥근 붓 한 획으로 다시 그렸고(곧은 세로획과 오른쪽 아래로 내려가는 짧은 꼬리), f는 가로획 아래 기둥을 곧은 한 획과 왼쪽으로 꺾인 짧은 발로 다시 그렸고, y와 g는 고리 진 꼬리를 j처럼 열린 꼬리로 다시 그렸고, 6은 기둥이 오른쪽으로 휘며 올라가게 다시 그렸고, 9는 그 6을 반 바퀴 돌린 모양으로 바꿨고, 8은 위 고리가 작은 둥근 붓 한 획으로 다시 그렸습니다. ģ는 쉼표를 g 위에 거꾸로 얹었습니다.
- '법'의 ㅂ 받침이 다른 ㅓ 글자보다 훨씬 넓어서 '업'의 받침으로 바꿨습니다.
- 원본에서 빈칸으로 나오던 한글 8,362자를 모두 원본에 있는 글자의 자모(초성, 모음, 받침)를 떼어 내 조합해 만들었습니다. 조합한 글자는 윗부분과 받침을 원본이 그린 같은 모음 글자들의 중앙값 자리에 맞췄고, 겹받침 글자는 초성과 모음을 원본이 그린 같은 계열 글자의 자리에 맞췄고, 쌍자음 초성 글자는 원본이 그린 받침 없는 글자를 눌러 받침을 붙였고, ㅙ ㅞ 글자는 원본의 ㅚ ㅟ 글자에 원본의 ㅐ ㅔ를 붙였고, 받침은 윗부분과 겹치지 않게 띄웠습니다.
- 원본 윤곽선의 2단위보다 짧은 선분을 지우고, 획 굵기를 조정할 때 점이 덜 움직여 생기던 혹을 없앴습니다(받침 ㄹ, 키릴 И Н의 모서리 등).
- 악센트가 붙은 라틴 글자(à é ñ ç 등)와 강세 부호가 붙은 그리스 문자(ά έ ή 등)를 원본의 글자와 악센트 기호로 만들었습니다.
- \ 자리에 원화 기호 대신 /를 좌우로 뒤집은 역슬래시를 넣었습니다.
- * 를 + - = 와 같은 높이 가운데로 내렸습니다.
- 박스 선 128자, 블록 32자, 점자 256자, Powerline 7자는 칸에 맞춰 새로 그렸습니다(원본에 있던 박스 선도 포함).
- 라틴 확장-A, 위·아래 첨자, • ✓ ✗ ‹ › „ ‚ ‼ µ ¦ ¯ � ς ⏺ ⎿ 와 제어 문자 그림 기호(␀ ␛ ␡ 등 39자)를 원본 글자와 획으로 만들었습니다.
- 조합형 자모(U+1100~)를 넣고, 자모로 분해된 한글(macOS 파일 이름 등)이 완성 음절로 보이도록 조합 규칙을 넣었습니다. 조합이 안 될 때는 자모를 정해진 자리(초성 위 왼쪽, 세로 모음 오른쪽, 가로 모음 초성 밑, 받침 아래)에 그리고, 짝이 없는 자모는 낱자 모양으로 따로 보이게 했습니다. 초성 채움(U+115F)과 중성 채움(U+1160)을 넣었습니다(보이지 않는 글자, ss04를 켜면 점으로 된 동그라미).
- ⑯~⑳, ⒃~⒇, ㈝ ㈞ 를 원본의 ⑮ ⒂ ㈜ 를 바탕으로 만들었습니다(숫자는 ⑮ ⒂ 의 숫자와 같은 크기).
- 화살표 ← ↑ → ↓ ↔ ↕ ↖ ↗ ↘ ↙ 를 -> 리거처처럼 원본의 > 와 - 로 다시 그렸습니다.
- 수학 연산자를 원본 글자와 리거처 부품으로 다시 그렸습니다(∪ ∩ ⊂ ⊃ ∈ 는 U, ≤ ≥ ≪ ≫ ≠ ≡ 는 < > = /, ∃ ⊥ 는 E T, ∂ 는 6, ∏ 는 ㅠ, ∑ 는 M, ≤ ≥ ⊆ ⊇ 의 아래 줄은 _, ∀ ∇ ∆ √ 는 둥근 획으로 새로 그림. √ 는 오른쪽 팔을 길게).
- 단위 기호(㎏ ㎞ ㎒ 등)를 원본의 라틴 글자를 이어 붙여 다시 만들었습니다. / 가 있는 단위(㎧ ㎨ ㎮ ㎯ ㏆)는 분수처럼 쌓았습니다.
- ogonek 글자(Ą ę Ų 등)의 갈고리를 둥근 획으로 새로 그려 글자 바닥에 붙이고, ſ 의 줄기를 매끄럽게 이었습니다.
- 낱자 자음(ㄱ ㄾ 등)은 원본의 비율과 가로 자리를 지키도록 두 칸에 놓고, 낱자 모음(ㅏ ㅜ ㅡ 등)은 두 칸의 가운데, 한글 음절의 가운데 높이에 놓았습니다.
- 분수 ¼ ½ ¾ ⅓ ⅛ 등을 분자, 가로줄, 분모를 위아래로 쌓아 한 칸에 넣었습니다.
- · ¢ £ ¥ ¬ ‾ 는 원본에서 전각 글자와 모양을 함께 써서 두 칸이었습니다. 한 칸짜리를 따로 만들었습니다.
- 가나(히라가나, 가타카나)는 두 칸에 두되 92%로 줄였습니다. 원본의 고딕 가나에서 중심선을 뽑아 꼬미 한글의 둥근 펜(꺾임 반지름 40, 둥근 획 끝, 갈고리 없음)으로 표준 필순에 맞춰 다시 그렸습니다. 작은 가나는 큰 가나를 줄여 만들고, 원본에 없는 ゕ ゖ 를 か け 에서 만들었습니다. 장음 기호 ー 와 탁점·반탁점 ゛ ゜ 를 원본의 ニ ガ パ 획으로 만들었습니다. 한자는 원본에 없어서 넣지 않았습니다.
- 반각 가타카나(U+FF61–FF9F)를 가타카나의 중심선을 반각 칸 폭으로 좁혀 같은 펜으로 그려 넣었습니다. ★ ☆ 는 반각 칸에 맞는 별로 다시 그렸습니다.
- Italic(KNPSKkomiMono-Italic.ttf): 라틴 문자와 한글, 가나, 전각 문자를 13° 기울이고, a d h m n u 의 오른쪽 기둥에 둥근 획 갈고리를, f 에 기준선 아래로 꺾이는 꼬리를 그리고, i j k y 를 필기체로 바꾸고, 기울인 뒤에도 모든 글자가 칸 안에 들어오게 맞추고, x 를 c 와 그 좌우 대칭을 맞붙인 ɔc 모양으로, l 을 아래에서 한 번 꼬인 고리 모양으로 바꿨습니다. 박스 선, 블록, 점자, Powerline은 똑바로 둡니다.
- 굵기: 원본 획(대문자 높이의 약 10.6%)을 기준본(base 폴더)으로 두고, Regular(400)는 약 12.5%, Bold(700)는 약 17%가 되도록 모든 획을 고르게 두껍게 했습니다(박스 선, 블록, 점자, Powerline은 그대로).
- 커닝을 빼고 코딩용 리거처(-> <- <-> => <=> == === != !== <= >= --> <-- ==> <== ~> <~ ~~> |> <| /\ \/, ... -> ⋯, := -> ≔)를 넣었습니다.
- 골라 쓰는 글자(기본은 꺼짐): ss01 && || -> ∧ ∨, ss02 원본의 0 i j l, ss03 Italic에서 필기체 대신 똑바른 글자를 기울인 모양, ss04 초성·중성 채움을 점으로 된 동그라미로, ss05 발 없는 곧은 f.
- 라틴, 그리스, 키릴 문자와 리거처에 ttfautohint로 힌트를 넣었습니다.

만드는 순서 (tools 폴더, 자세한 명령은 README.md):
1. make_mono_static.py  원본 OTF -> base/KNPSKkomiMono-Base.ttf
2. make_kana.py         원본 OTF의 가나 중심선 -> Base의 가나, 반각 가타카나, ★ ☆
3. make_italic.py       Base -> base/KNPSKkomiMono-BaseItalic.ttf
4. make_bold.py         Base, BaseItalic -> Regular, Italic, Bold, Bold Italic
